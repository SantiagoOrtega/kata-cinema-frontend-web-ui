# Kata Cinema Banboger Application

This repository contains the source code for a Cinema Management Application. The application allows users to manage movies, rooms and make reservations. It is built using Angular and TypeScript.

- Installation

## Installation

To install and run this application locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/SantiagoOrtega/kata-cinema-frontend-web-ui.git
   cd kata-cinema-frontend-web-ui
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   ng serve
   ```

4. Open your browser and navigate to `http://localhost:4200`.
